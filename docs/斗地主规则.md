# 斗地主规则说明

## 1. 基础规则

斗地主是一种三人对战的扑克牌游戏，通常使用一副 54 张牌，其中包含 4 个花色和 2 张大王、小王。玩家分为地主和农民两方，地主一人对抗两名农民。

## 2. 牌型说明

斗地主的牌型大致包括：

- 单张
- 对子
- 三张
- 三带一
- 三带二
- 顺子
- 连对
- 飞机
- 飞机带单/带双
- 四带二
- 炸弹
- 王炸

### 2.1 关键约束

- 顺子不能包含 2 和王
- 飞机必须连续且每组均为三张
- 四带二不能被当作炸弹
- 炸弹大于所有普通牌型
- 王炸最大，炸弹次之

## 3. 牌型比较

当两家出牌牌型相同，比较主牌大小；除炸弹以外，长度必须一致。若牌型不同，只能在相同牌型下比较。比较逻辑如下：

- 王炸 > 炸弹 > 普通牌型
- 同牌型比较主牌值
- 炸弹比较炸弹大小
- 牌型不合法时不能出牌

## 4. 出牌策略

### 4.1 地主策略

- 优先控制节奏，拿住主动权
- 先手时尽量压制农民
- 在残局中需要保留炸弹用于关键时刻

### 4.2 农民配合

- 上游顶牌，避免地主轻松压制
- 下游尽量出小牌，争取跑牌顺畅
- 需要配合传牌与顶牌策略

## 5. 实现说明

本项目中的规则引擎位于：

- src/js/rules/DoudizhuRule.js
- src/js/game/DoudizhuGame.js

规则引擎主要负责：

- 牌型识别
- 合法性校验
- 主牌大小比较
- 提示功能
- 成牌搜索

## 6. 关键示例

```js
const result = DoudizhuRule.judge(cards);
if (result.isValid) {
  console.log('合法牌型：', result.type, result.mainValue);
}
```

上述逻辑用于测试一手牌是否符合斗地主规则，并输出牌型编号和主牌值。

## 7. 设计目标

本规则实现的目标不是完整对战引擎，而是让前端原型具备：

- 明确的牌型判断
- 合法出牌判定
- 对比逻辑
- AI 可直接复用的规则接口
